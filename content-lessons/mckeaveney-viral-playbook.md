# Viral video playbook (from @robertmckeaveney, 8 reels transcribed)

## Lessons
1. **Watch time is king.** No watch time, no viral. Aim for average watch time above video length (loops, rewatch bait).
2. **Hook, buildup, payoff.** Hook makes viewer ask a question. Buildup strengthens it. Payoff answers it at the end. Never leave a moment with no open question.
3. **Open loops.** Chain several hooks and payoffs (3 mini-questions beat 1). Cut back and forth so the loop stays open until the end.
4. **Stitch hook.** Start with someone else's clip, then enter with your own. Viewer wonders how yours relates.
5. **Challenge hook.** "Only 1% can pause at the right frame." Red outline, text popping up, "so close" on a near miss: people retry, watch time spikes.
6. **Take a proven viral format, add your own twist or niche.** Don't reinvent. Copying a format is fine.
7. **Convert, don't only entertain.** Hide the offer inside the payoff (pause frame says "DM screenshot for discount": ~29k DMs).
8. **Three E's.** Every viral video has at least one: entertainment, educational, emotional value.
9. **Baseline rule.** 3 flops in a row shrink the next video's first audience. 3 wins in a row grow it. Post consistent winners.
10. **Read the retention graph.** Drop at start = hook problem. Mid dip = buildup. Late drop = payoff.
11. **Iterate.** Winner? Change 1-2 parts and repost in a month. Make 5 versions, post all to Trial Reels, push the best to everyone.
12. **Mix content goals.** Some videos for views, some for follows, some for sales. Find the missing one and fix it.
13. **Branding and CTA.** Every video ends with a clear reason to follow ("content worth stealing"). Product CTA only after the open loop is set.

## Script template (Reels / Shorts, 15-45s)
| Time | Part | What to do |
|---|---|---|
| 0-2s | Hook | Visual question or challenge. Text on screen. No intro, no "hey guys". |
| 2-5s | Raise stakes | One line: why the answer matters, or a "so close" tease. |
| 5-25s | Buildup | 2-3 mini open loops. Cut every 1-2s. Answer one, open the next. |
| mid | Offer | Slip product or topic in as part of the story, not as an ad. |
| last 3-5s | Payoff | Answer the main question. End on a frame that makes people replay. |
| end | CTA | One line: follow for X. Loop the last frame into the first. |

## Fill-in script
```
HOOK (0-2s):   "[Surprising claim / challenge]. Only [x]% can [do thing]."
               On screen: [text + visual that sets the question]
STAKES (2-5s): "Here's why [claim] matters / watch what happens when [setup]."
LOOP 1:        Question -> mini payoff -> new question
LOOP 2:        Question -> mini payoff -> new question
OFFER:         "This is how [your product/idea] fits: [one line]."
PAYOFF:        Answer the hook's question. Show the result.
CTA:           "Follow for [niche promise]." Cut so the end flows into the start.
```

## Platform notes
- **Instagram Reels:** 7-30s loops, text-heavy first frame, Trial Reels for testing versions, DM-for-code CTA.
- **YouTube Shorts:** same structure, hook visible in the first 1s, retention graph in Studio shows where to fix.
- **YouTube long form:** same hook, buildup, payoff idea. Re-hook every 30-60s.
