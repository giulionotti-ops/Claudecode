Neesmo guide

Everything you need to run Claude Code from one screen.

Getting started

  1. On your server, sign in to Claude Code once: claude.
  2. Run the installer from the Neesmo folder: ./install.sh (add --all to install every extra without questions).
  3. Open Neesmo. The first visit asks for the setup code from the server log and a password you choose: 
    journalctl -u neesmo | grep -i "setup code"
  4. Open Settings (the gear) and add your agents.

Commands

Hold the mic or type in the bar at the bottom. Neesmo answers, and passes jobs to the right agent. Ask things like:

  • "What is every agent doing right now?"
  • "Ask the website agent to fix the contact form."
  • "Summarise today's commits."

Chat screen

Tap the command bar to open the chat. The cards step aside and the HUD stays. Typed answers can use lists and code. Use the paperclip to attach files (up to 50 MB each), New chat to start fresh, and ← Back or Esc to return.

Agents

An agent is a Claude Code session with its own folder and job brief. Each one is a card on the main screen.

  • Add or edit: Settings → Agents. Give it a name, a folder (inside your home folder) and a short job description.
  • Open a card to see its status, today's numbers and what it's doing now. Details shows requests, activity, tools and commits.
  • Chat with it from the card. The chat is the agent's real Claude Code session: an interactive claude running in a tmux session in the agent's folder, the same thing you'd get in a terminal there. Neesmo starts it the first time you write (continuing the folder's last conversation), types your messages into it and shows the replies and tool steps. Close the card any time: it keeps working and Neesmo notifies you when it replies.
  • Questions and permissions: when Claude asks you to pick an option, the choices show up as buttons in the chat.
  • Use a terminal too: the card shows the command, for example tmux attach -t neesmo-website. Whatever you type there shows up in Neesmo, and the other way round.
  • Stop presses Esc in the session; New thread runs /clear.
  • Agent settings: the gear in an agent's chat (or its row in Settings → Agents) opens three tabs. Appearance: name, card label and colour. Job: what it works on, its folder and how it should work. Plugins: only the plugins that fit its job (a video agent doesn't get code-review tools); switches apply to that agent's folder alone, and its next session picks them up.
  • Claude app: the sessions Neesmo starts also join Remote Control, so you can open the same chat in the Claude app on your phone or desktop (the installer sets NEESMO_RC=1; it needs a Claude.ai login, so set it to 0 in ~/.config/neesmo/neesmo.env if you use an API key). A folder already run by claude remote-control is shown read-only.

Settings

Tap the gear. Settings are split into tabs:

  • General: the welcome greeting Neesmo shows (and can say out loud) when you open it. It is saved on the server, so every device greets the same way. Set your name and the message; {greeting}, {name} and {busy} are filled in for you. Also the voice.
  • Appearance: colour, text size, the big NEESMO lettering, scan lines (thin lines over the screen like an old CRT monitor) and calm motion. Saved per device.
  • Agents: add, edit and reorder agents. Drag a row, or drag the cards on the home screen; on a phone, hold a card for a moment, then move it. It snaps into place and the order is saved on the server.
  • System: links to this guide, the website and the open-source licenses, and switches for the universal Claude Code plugins and skills (the ones every session on the server gets). Job plugins (code, git, GitHub, web) sit in a folded group below: switched on there they run in every chat, so it is better to switch them on per agent. Popular plugins from the official store are listed too and install when you switch them on. Changes apply to sessions started afterwards. Skills inside a project folder belong to that project and are not listed.
  • License: your key, and every open-source part Neesmo ships or installs with its license.

Approvals

When an agent needs permission for something, Neesmo sends a notification. Approve, deny, or ignore it right from the notification list without opening it. Ignored requests time out on their own.

Phone app

On iPhone, open Neesmo in Safari, tap Share → Add to Home Screen, then open it from the home screen and turn on notifications from the bell. On Android, use the browser menu → Install app.

Access and login

Neesmo listens on 127.0.0.1. To reach it from anywhere, put it behind a Cloudflare Tunnel (./install.sh --tunnel shows how) or your own private network. Each device signs in once and is remembered for a year. See and sign out devices in Settings → Devices.

Bundle

  • OmniRoute: a local gateway to free models, for cheap text jobs. Add providers with omniroute providers add.
  • graphify: builds a knowledge graph of a codebase so agents find code faster.
  • claude-mem: long-term memory across Claude Code sessions.
  • caveman: a plugin that makes Claude answer short and plain while keeping every technical detail. Turn it off in Settings → System if you prefer long answers.
  • Skill pack: 55 skills for engineering, code review, video making, reading links and finding the right skill for a job.

License

Neesmo runs as a 14-day trial. When it ends, your settings and agents stay, but Neesmo stops answering until you add a key. Paste your key in Settings → License.

  • Store keys (from the purchase email) are activated once over the internet, then checked with the store about once a week. If the store can't be reached, Neesmo keeps working for 30 days.
  • A key works on 2 servers. Remove key frees the seat, so you can move Neesmo to a new server.
  • Early access: buy once, and every update is yours for free, including the full release.

Troubleshooting

  • Agents show offline: they come online when you first write to them. Check that Claude Code is signed in on the server (claude) and that tmux is installed.
  • No notifications on iPhone: they only work in the home-screen app, not in Safari.
  • Service logs: journalctl -u neesmo -f (add --user if you installed without root).
  • Forgot the password: stop the service, delete ~/.config/neesmo/auth.json, start it again and use the new setup code.
