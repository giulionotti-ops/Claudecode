Glazier of Terra is a YouTube channel that tells Warhammer 40,000 lore as short animated films in a stained-glass style.

The app

The Glazier of Terra app is a private tool used only by the channel owner to upload and schedule the channel's own videos on YouTube and to read the channel's own analytics, so future videos can be improved. It does not access any other user's account or data.

Uses YouTube API Services
