Neesmo questions before you buy

Do I need a VPS for Neesmo?

No. A home PC running Linux works, and so does Windows through WSL. Agents only work while it is switched on, so a small VPS suits you if you want them running all day.

How does the Neesmo license check work?

Your own computer checks the key. It checks in with the store about once a week, and a key works on 2 computers.

Is Claude usage included in Neesmo?

No. Neesmo runs on your Claude Code, signed in with your own Claude plan or API key.

Do I pay again for Neesmo updates?

No. Buy at the early-build price and every update is free, including the full release.
